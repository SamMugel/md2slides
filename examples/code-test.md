# Code Examples

## Python Code

Here is some Python code:

```python
def hello(name):
    """Say hello to someone."""
    print(f"Hello, {name}!")

if __name__ == "__main__":
    hello("World")
```

## JavaScript Code

Here is some JavaScript:

```javascript
function greet(name) {
    console.log(`Hello, ${name}!`);
}

greet("World");
```
